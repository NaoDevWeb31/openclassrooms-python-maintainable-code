# Jeu de cartes

Projet de création d'un jeu de 52 cartes standard réalisé dans le cadre du cours [Écrivez du code Python maintenable](https://openclassrooms.com/fr/courses/7160741-ecrivez-du-code-python-maintenable) proposé par OpenClassrooms.

Ce projet permet de mettre en pratique l'architecture MVC (Modèle-Vue-Contrôleur) et les principes SOLID.

## Installation

Le projet utilise l'environnement virtuel Python du repository principal.

Le fichier `requirements.txt` d'origine est conservé à titre de référence. Les outils de développement utilisés sont ceux configurés dans l'environnement virtuel du repository principal.

## Utilisation

Depuis la racine du repository, avec l'environnement virtuel Python activé :

```bash
python jeu-de-carte/main.py
```
